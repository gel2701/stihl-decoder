Date: 2026-11-03
Branch: `feat/phase61d-real-exploded-diagrams`
Baseline: `main` @ `feb130a`

## 1. Executive summary

- **Real, legally usable exploded-view images on the public site: 0.**
- Every "diagram" affordance previously pointed at an internal section anchor, not an image.
- Labels that promised a drawing ("Bekijk in explosietekening", "Explosietekeningen", "exploded views") are replaced with **"Onderdelenlijst met tekeningposities"**.
- No image was embedded, hotlinked or copied. No CAPTCHA/Cloudflare bypass, no new scraping, no new catalog acquisition.
- Catalog and SEO invariants unchanged: 18,373 parts, 843 indexable part pages, 1,024 sitemap URLs, tag `srihldecoder2-21`.

## 5. Implementation

1. **New** `src/components/DiagramAvailabilityNotice.js`
   - States explicitly: real STIHL exploded-view images are not available; the page shows the parts list with diagram positions.
   - Rendered on every model parts page, model page parts section, and part detail "Montagelocatie & tekeningposities" block.
2. **Honest labels** (no image promise):
   - `index.html`: "Bekijk in explosietekening" → "Onderdelenlijst met tekeningposities".
   - `ModelPageTemplate.js`: heading, intro, section cards, CTA and footer copy.
   - `ModelPartsPageTemplate.js`: breadcrumb, title, meta description, section navigation, catalog intro.
   - `PartsDiscoveryPageTemplate.js`: hub title, meta description, model block label.
   - `server.js`: series page link and popular-model block.
3. **`DirectPartsEngine.js`**: adds `diagram_kind`/`diagram_label`; `diagram_url` remains the same section anchor (contract preserved).
4. **No image rendering added**: no `<img>`, no external image CDN, no zoom UI for artwork that does not exist. Nothing to hotlink, nothing to misrepresent.
5. **Tests**: new `tests/phase61d_diagram_honesty.test.js` (6 contracts) registered in `tests/run_current_production_tests.js`. Updated assertions in `phase3`, `phase54c`, `phase56a`, `phase56d`, `phase56e`.

## 6. What is still missing (to increase coverage)

1. **Licensed STIHL IPL artwork** for the priority models. Needed: written permission or a licensed parts-catalog feed. Without it, embedding is copyright infringement.
2. **Image-level position coordinates** (x, y per position) if interactive hotspots are ever wanted. Current data has position numbers only.
3. **Documented provenance per drawing**: model, variant/serial scope, diagram code, revision date. GHS rows have model + config keys but no licence.
4. **Hosting**: even with a licence, images should be served first-party (AVIF/WebP, responsive `srcset`) rather than hotlinked.
5. **Coverage path**: request STIHL authorised-dealer/IPL access, or use a licensed catalog vendor that permits sublicensing of diagram images.
